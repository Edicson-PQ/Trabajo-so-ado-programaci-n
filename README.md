## Parte 1 — Investigación del Trabajo Soñado

### Perfil profesional seleccionado

**Full Stack Engineer con especialización en Arquitecturas Cloud-Native e Integración de IA**

### Justificación del perfil

A lo largo del tiempo como estudiante de ingeniería en sistemas he elegido este perfil por dos razones concretas:

1. **Visión integral del producto:** Un ingeniero Full Stack comprende el sistema completo, desde la interfaz de usuario hasta la infraestructura. Esta visión integral es el camino natural hacia roles de liderazgo técnico (Tech Lead, Software Architect) y hacia el emprendimiento tecnológico, que es el objetivo de largo plazo.

2. **Alta demanda en el mercado regional y remoto:** El perfil Full Stack con conocimiento en cloud y herramientas de IA tiene una demanda creciente en Costa Rica y en el mercado LATAM de trabajo remoto. Abre puertas tanto a empresas locales como a startups y empresas de EE.UU. que contratan talento remoto.

### Enfoque del sitio web

El sitio no es un CV estático. Es una **plataforma de mis servicios y marca personal** orientada a atraer clientes freelance y empleadores remotos. Refleja el perfil investigado: demuestra mi capacidad técnica real a través de tres demos interactivos, comunica servicios concretos, y permite contacto directo.

## Parte 3 — Desarrollo Web

### Tecnologías y justificación

- **HTML5:** Estructura semántica usando `header`, `nav`, `main`, `section`, `article`, `footer`. Sin `<div>` para layout cuando existe elemento semántico apropiado. Validado con W3C Validator.
- **CSS3:** Custom Properties (`--var`), Flexbox, CSS Grid, `@keyframes`, `@media` queries (breakpoints en 768px y 1100px), `transition`, `animation`. Sin frameworks.
- **JavaScript (uso limitado y justificado):** Solo para funcionalidades imposibles en CSS: modo oscuro con `localStorage`, canvas de partículas con `requestAnimationFrame`, efecto typewriter, contador animado de estadísticas y sistema de scroll reveal con `IntersectionObserver`.

### Animaciones implementadas

| Animación | Tecnología | Descripción |
|---|---|---|
| Partículas en el Hero | Canvas API (JS) | Red de puntos conectados por líneas dinámicas |
| Typewriter en el H1 | Vanilla JS | Escritura letra a letra con cursor parpadeante |
| Gradiente animado en el título | CSS `@keyframes` | Shift de color azul→violeta→cyan continuo |
| Scroll Reveal con stagger | IntersectionObserver | Cards y secciones aparecen secuencialmente al hacer scroll |
| Metro Map de Skills | CSS + scroll JS | Líneas de rail se dibujan progresivamente al bajar la página |
| Tilt 3D en cards | JS `mousemove` | Efecto perspectiva 3D en hover de tarjetas de proyecto |
| Ripple en botones | JS `click` | Onda visual al hacer clic en cualquier botón |
| Cursor spotlight | CSS custom properties | Halo suave que sigue el cursor |
| Float del hero card | CSS `@keyframes` | Flotación continua de la tarjeta de perfil |
| Contador de estadísticas | JS `requestAnimationFrame` | Números suben animados al entrar en viewport |

### Responsive

- `@media (min-width: 768px)` — layout de dos columnas para tablet y desktop
- `@media (min-width: 1100px)` — grids de tres columnas para pantallas grandes
- Menú hamburguesa implementado con checkbox CSS (sin JavaScript)
- Todos los tamaños de fuente usan `clamp()` para escalar entre dispositivos

### Modo oscuro

Implementado con `data-theme="dark"` en el elemento `<html>` y CSS custom properties que cambian la paleta completa. La preferencia del usuario se persiste con `localStorage` y se respeta la configuración del sistema operativo con `prefers-color-scheme`.
