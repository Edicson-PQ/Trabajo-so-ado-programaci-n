
  # Professional Portfolio Website (Static)

  This portfolio has been migrated to a static implementation using only HTML5 and CSS3 for structure, styling, responsiveness, and animations.

  ## Stack

  - `index.html`: full page structure and content
  - `styles.css`: typography, layout, responsive design, and animations
  - No component runtime and no UI framework dependencies

  ## Run locally

  1. Install dependencies:
    `npm install`
  2. Start local server:
    `npm run dev`
  3. Build static assets:
    `npm run build`
